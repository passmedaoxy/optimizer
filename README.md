# Optimizer archive

Every old build of [Optimizer](https://github.com/passmedaoxy/optimizer) worth keeping (this is the `archive` branch), from the first Python script to the last
console version. They're here for history and for fun. **None of them are supported**, and the
current version is better and safer in every way: [get the latest release](https://github.com/passmedaoxy/optimizer/releases/latest).

> **Before you run any of these:** try them on a spare PC or a virtual machine. Old builds change
> Windows settings and don't always put everything back. Each zip has a `READ ME FIRST.txt` with
> what that version changes and how to undo it.

| Version | Date | What it was |
|---|---|---|
| [v1.0](https://github.com/passmedaoxy/optimizer/releases/tag/1.0) | Jan 5, 2026 | The first build. A Python console script: high priority, 1 ms timer and Ultimate Performance while a game runs. |
| [v1.1](https://github.com/passmedaoxy/optimizer/releases/tag/1.1) | Jan 7, 2026 | Adds a tray icon and its own game lists. |
| [v1.4.2](https://github.com/passmedaoxy/optimizer/releases/tag/1.4.2) | Feb 3, 2026 | The last Python version, first called Optimizer: commands, setup wizard, presets, closing apps, crash recovery, run on startup. |
| [v2.6.5](https://github.com/passmedaoxy/optimizer/releases/tag/2.6.5) | Mar 6, 2026 | The C++ rewrite, still a console app, with around 40 tweaks. A Debug build: needs Visual Studio's C++ tools to run. |

The 1.x versions are Python programs packed with PyInstaller, so antivirus often flags them by mistake.

> **Only these builds survived.** Every other version from before 2.8.3 is lost for good.
> These are the only early builds left. The versions in between, and anything else before 2.8.3, are lost to time.
